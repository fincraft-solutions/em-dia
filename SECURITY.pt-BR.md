# Segurança

Evite compartilhar dados de clientes, extratos, documentos fiscais privados, credenciais ou chaves de API em issues e pull requests. Sempre que possível, reproduza o problema com dados fictícios.

Para comunicar uma vulnerabilidade, entre em contato com os responsáveis por um canal privado adequado antes de divulgar detalhes. Não inclua informações exploráveis em uma issue pública.
