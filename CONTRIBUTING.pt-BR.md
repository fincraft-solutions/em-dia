# Contribuindo com Em Dia

Uma boa issue começa com um caso que outra pessoa consiga reproduzir. Inclua a entrada, o resultado esperado e o resultado observado. Utilize registros fictícios em exemplos e issues públicas.

Para contribuir com código, abra um pull request com uma descrição objetiva e as verificações pertinentes. Comece pelo [`README.pt-BR.md`](README.pt-BR.md) e explore o [código](src/).

Para relatar vulnerabilidades, consulte [SECURITY.pt-BR.md](SECURITY.pt-BR.md).
